* **Sample Variance** – Measures how spread out sample data is around its mean using (n-1) in the denominator. It estimates the variance of the entire population from a sample.

* **Sample Standard Deviation** – The square root of the sample variance, representing the average spread of data in the original units. It is widely used to measure variability in sample datasets.

* **Covariance** – Measures whether two variables change together. A positive value indicates they tend to increase together, while a negative value means one tends to increase as the other decreases.

* **Correlation Coefficient** – Measures the strength and direction of the linear relationship between two variables. Its value ranges from **-1** (perfect negative correlation) to **+1** (perfect positive correlation).

* **Percentiles** – Divide a dataset into 100 equal parts to show the relative position of a value. For example, the 90th percentile means the value is greater than 90% of the data.

* **Quartiles** – Split a dataset into four equal parts: Q1 (25%), Q2 (median), and Q3 (75%). They are commonly used to understand the distribution of data.

* **Interquartile Range (IQR)** – The difference between the third quartile (Q3) and the first quartile (Q1). It measures the spread of the middle 50% of the data and helps detect outliers.

* **Z-score** – Indicates how many standard deviations a value is above or below the mean. It is useful for comparing values from different datasets and detecting unusual observations.

* **Min-Max Normalization** – Scales data to a fixed range, typically **0 to 1**, while preserving the relative differences between values. It is commonly used before training machine learning models.

* **Robust Mode Implementation** – Determines the most frequently occurring value while correctly handling ties, multiple modes, and datasets with no repeated values. It provides more reliable mode calculations than simple implementations.

* **Weighted Mean** – Computes an average where each value contributes according to its assigned weight. It is useful when some observations are more important than others.

* **Bootstrap Confidence Intervals** – Estimates confidence intervals by repeatedly resampling the data with replacement. This non-parametric approach is useful when the underlying distribution is unknown.

* **Hypothesis Testing** – Uses statistical methods to determine whether there is enough evidence to reject a null hypothesis. It helps make data-driven decisions based on sample evidence.

* **Linear Regression Utilities** – Provides tools for fitting a linear relationship between variables, making predictions, and evaluating model performance. These utilities are fundamental in predictive analytics and machine learning.

* **Visualization using Matplotlib** – Creates plots such as histograms, scatter plots, box plots, and line charts to explore and communicate data visually. Visualizations make patterns, trends, and outliers easier to identify.

* **Unit Tests with pytest** – Ensures statistical functions behave correctly by automatically testing expected outputs and edge cases. It improves code reliability and simplifies maintenance as the project grows.
