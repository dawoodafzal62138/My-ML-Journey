# Mandelbrot Set Generator

A high-performance **Mandelbrot Set Generator** built with **Python**, **NumPy**, **Numba**, and **Pillow**. This project generates beautiful Mandelbrot fractal images and supports creating smooth infinite zoom animations by rendering approximately thousand of high-resolution frames.

---

## Preview

The Mandelbrot Set is one of the most famous mathematical fractals. It is generated by repeatedly applying the equation

$$
z_{n+1}=z_n^2+c
$$

starting with

$$
z_0=0
$$

If the sequence never escapes to infinity, the point belongs to the Mandelbrot Set.

Although the equation is extremely simple, it produces infinitely complex and self-similar patterns.

# Mathematical Background

Every pixel represents a complex number

$$
c=x+yi
$$

The algorithm repeatedly computes

$$
z_{n+1}=z_n^2+c
$$

If

$$
|z|>2
$$

the point escapes and is colored according to the number of iterations required.

Otherwise, it belongs to the Mandelbrot Set and is colored black.

---

# How the Generator Works

1. Create a grid of complex numbers.
2. Iterate every point independently.
3. Check whether the value escapes.
4. Store the escape iteration.
5. Convert iterations into RGB colors.
6. Save the generated image.

---

# Infinite Zoom

The zoom animation works by

- Selecting a center point
- Rendering one frame
- Shrinking the viewing window
- Increasing the iteration count
- Rendering the next frame

Repeating this process thousands of times creates an infinite zoom effect.

---

# Adjustable Parameters

The animation can be customized by modifying:

| Parameter | Description |
|-----------|-------------|
| image_width | Width of image |
| image_height | Height of image |
| total_frames | Number of animation frames |
| zoom_factor | Zoom speed |
| center_x | X-coordinate of zoom target |
| center_y | Y-coordinate of zoom target |
| max_iterations | Fractal detail level |

# Performance Optimization

This project uses several optimization techniques:

- Numba JIT Compilation
- Parallel execution with `prange`
- NumPy arrays
- Fast mathematical operations
- Efficient memory allocation
- Incremental iteration increases during deep zoom

These optimizations significantly reduce rendering time compared to a pure Python implementation.

---

# Coloring Algorithm

Pixels outside the Mandelbrot Set are colored using a smooth RGB gradient based on the escape iteration count.

Pixels inside the Mandelbrot Set remain black.

This produces visually appealing fractal images with smooth transitions.

Example:

```bash

```
