# 🎲 Random Walk Simulation in Python

A comprehensive Python project that demonstrates **Random Walks** in **1D**, **2D**, and **3D** using **NumPy** and **Matplotlib**. This project explores one of the most fundamental concepts in probability theory and stochastic processes through interactive simulations and visualizations.

---

## 📖 Overview

A **Random Walk** is a mathematical process that describes a path consisting of a sequence of random steps. It is widely used in:

- 🎲 Probability Theory
- 📊 Statistics
- ⚛️ Physics (Brownian Motion)
- 🧬 Biology (Molecule Diffusion)
- 💹 Finance (Stock Price Models)
- 🤖 Machine Learning
- 📡 Robotics and Navigation

This project implements random walks in one, two, and three dimensions while providing intuitive visualizations of how randomness accumulates over time.

# Features

## 1️⃣ One-Dimensional Random Walk

- Simulates movement along a straight line.
- Step size = ±1
- Configurable number of steps.
- Tracks the position after every step.
- Plots the walk against time.

### Visualization

- Position vs Step Number
- Starting Point
- Ending Point

---

## 2️⃣ Two-Dimensional Random Walk

The walker moves randomly in

- Left
- Right
- Up
- Down

### Visualization

- Complete path
- Start point
- End point
- Color gradient representing time progression
- Grid for easier interpretation

---

## 3️⃣ Three-Dimensional Random Walk

The walker moves randomly in

- ±X direction
- ±Y direction
- ±Z direction

### Visualization

- Interactive 3D trajectory
- Start point
- End point
- Color progression
- Rotatable 3D graph
